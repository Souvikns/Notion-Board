# Product

## Register

brand

## Users

Developers and open-source maintainers who live in both GitHub and Notion. They manage issues in repositories and track work in Notion databases. They are technical, impatient with friction, and respect tools that work without configuration. They find Notion-Board through GitHub's Actions marketplace or a colleague's recommendation, often mid-workflow.

## Product Purpose

Notion-Board is a GitHub Action that automatically syncs GitHub Issues to a Notion database: title, labels, and state, every time an issue is opened, edited, or commented on. It exists because copy-pasting issue data between tools is a waste of developer time. Success looks like a developer adding one workflow file, setting three secrets, and never thinking about sync again.

## Brand Personality

Warm, approachable, technical. Warmth comes through ease and clarity, not decoration. Approachable means the landing page should feel like a colleague showing you something useful, not a sales pitch. Technical means the page earns credibility by showing real code and real configuration, not abstract metaphors. Confident enough to let whitespace breathe. Precise enough that every element earns its place.

## Anti-references

- Generic SaaS landing pages with hero metrics, testimonial carousels, and gradient-everything
- Vercel's marketing surface as a direct visual clone (inspire, don't duplicate)
- Notion's own marketing pages (avoid brand confusion)
- Developer tools that mistake "dark mode" for personality
- Landing pages where every section is an identical card grid

## Design Principles

- **Show the thing.** The workflow YAML IS the hero content. Real code beats abstract descriptions.
- **Earn every element.** If a section can be removed without losing meaning, remove it.
- **Warmth through craft.** Micro-interactions, precise spacing, and intentional motion make the page feel alive and approachable, not decorative embellishment.
- **Expert confidence.** The audience ships code daily. Talk to them like a colleague, not a customer.
- **Sync is the story.** The visual vocabulary should echo the product: things moving, connecting, updating from one place to another.

## Accessibility & Inclusion

WCAG 2.1 AA minimum. Reduced motion support for all animations. Sufficient color contrast on all text, including the dark-band sections. No information conveyed by color alone.
